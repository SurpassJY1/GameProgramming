# Dungeon Key Run

Unity 2D dungeon game project.

## Assets and Licenses

Full asset credits, source URLs, licenses, and local file paths are documented in `CREDITS.md`.

Current main visual assets include:

- Project-generated readable pixel sprites for the player, floor, wall, key, and exit door in `Assets/StreamingAssets/generated/clear-dungeon/`.
- Kenney Tiny Dungeon, Kenney UI Pack, Kenney Interface Sounds, Kenney RPG Audio, and Kenney Impact Sounds under CC0.
- `"8bit Dungeon Level"` by Kevin MacLeod for background music under Creative Commons Attribution 4.0.

The project-generated sprites are original module work and do not require an external image license. Third-party assets remain credited even where the license does not require attribution.
