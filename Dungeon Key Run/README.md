# Dungeon Key Run

Dungeon Key Run is a Unity 2D top-down dungeon shooter. The player clears
procedurally rebuilt dungeon floors, collects a key, reaches the exit, survives
boss encounters, and tries to improve the saved local best score.

Built with **Unity 2022.3.62f1**.

## Quick Start

1. Open this folder as a Unity project.
2. Open `Assets/Scenes/DungeonKeyRun.unity`.
3. Press Play in the Unity Editor.

Unity cache folders such as `Library/`, `Logs/`, `Temp/`, `obj/`, and
`UserSettings/` are local generated files and are not required source files.

## Demo Guide

The core loop is:

1. Explore the current floor.
2. Defeat enemies for XP.
3. Collect the gold key.
4. Reach the blue exit door.
5. Choose a passive floor-clear upgrade.
6. Continue to deeper floors and boss encounters.

Every third floor is a boss floor. On boss floors, the exit stays sealed until
the boss is defeated.

### How to Play

- Move with WASD or the arrow keys.
- Aim with the mouse and hold the left mouse button to shoot.
- Press ESC to pause.
- Collect the gold key on each floor, then reach the blue exit door.
- Every third floor is a boss floor. On boss floors, the exit stays sealed until the boss is
  defeated.
- Defeating enemies grants XP. Leveling up opens a weapon upgrade choice.
- Clearing a floor opens a passive upgrade choice before the next floor starts.
- The HUD shows floor, lives, key state, defeated enemies, score, level, XP, time, and the current
  objective.
- After a run ends, the game records local best score, best floor, and a Top 5 leaderboard with
  PlayerPrefs.

## Implemented Features

- Top-down player movement, mouse aiming, shooting, damage, invulnerability
  frames, lives, and camera follow.
- Enemy spawning, enemy defeat tracking, score, XP, leveling, and weapon upgrade
  choices.
- Boss floors every third floor, with sealed exits until the boss is defeated.
- Key pickup and exit-door progression for normal floors.
- Passive upgrade selection between floors.
- Start, pause, game-over, restart, and leaderboard UI flows.
- HUD objective text, floor/life/key/score/XP/time readouts, and tutorial
  prompts.
- Runtime fallback art/audio generation so the game still runs if optional
  external files are missing.
- Third-party image/audio loading from `Assets/StreamingAssets/thirdparty/`
  with license and attribution files kept beside the assets.

## Project Layout

```text
Assets/
+-- Scenes/
|   +-- DungeonKeyRun.unity ........ main playable scene
+-- Scripts/
|   +-- GameBootstrap.cs ......... scene setup and runtime wiring
|   +-- GameManager.cs ........... run state, floors, scoring, upgrades
|   +-- Player.cs ................ movement, health, collisions
|   +-- PlayerCombat.cs .......... aiming, shooting, weapon upgrades
|   +-- Enemy.cs ................. enemy and boss behaviour
|   +-- HUD.cs ................... in-game readouts and objective text
|   +-- Menus.cs ................. start, pause, game-over, leaderboard UI
|   +-- UpgradeSelectionUI.cs .... weapon upgrade choices
|   +-- PassiveUpgradeSelectionUI.cs
|   +-- Art2D.cs ................. asset loading plus procedural fallbacks
+-- StreamingAssets/
    +-- generated/ ............... project-generated sprites
    +-- thirdparty/ .............. Kenney and Incompetech assets + licenses
```
